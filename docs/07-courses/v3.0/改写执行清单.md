## 写作风格规范

1. **每课开头必须有"本课解决什么问题"**,用 1 句话点出
2. **每课结尾必须有"实操作业"**,让用户用本系统真实跑一次
3. **截图引用**:`images/lesson-XX/XX-xxx.png` 路径
4. **代码示例**:Python/JavaScript 都要能直接运行
5. **避免空话**:少讲理论,多讲"在系统里怎么点"
6. **不写"目标价/看涨/看跌"那种合规官话**,保留"买入/止损/止盈"等口语(用户已确认)
7. **跨课引用**:用相对路径 `[lesson-05](file:///.../lesson-05-xxx.md)`
